# 적 VFX 개발 예정

이 문서는 적 애니메이션과 별도로 Unity에서 연결해야 할 VFX 개발 항목을 기록한다. 아래 항목은 기획 확정 및 구현 대기 상태이며, 실제 셰이더·파티클·게임 연결의 완료 기록이 아니다.

## Witch 사망 — 몸·의상 소멸 후 지팡이 소멸

**결정일: 2026-11-02 KST / 상태: 계획 확정, 구현·Unity 검수 미완료.**

사용자 승인 방향은 해골과 의상을 함께 재·보라색 마력으로 흩어 없애고, 놓인 지팡이는 바닥으로 쓰러져 멈춘 뒤 사라지는 것이다. 몸 전체가 살짝 반동·처짐을 보인 후 소멸한다. 의상에는 로브·양소매·목걸이가 모두 포함된다. 이전의 빈 로브가 길게 접혀 바닥에 남는 사망 연출은 이 결정으로 대체한다.

애니메이션 계약은 최종 납품의 [Witch_Clips.json](../../Art/Enemy_Models/05_Witch/Witch_Clips.json)과 [Witch 인계](../../Art/Enemy_Models/05_Witch/Handoff.md)를 따른다. 모든 프레임 표기는 **60fps, 클립 로컬 0 시작**이다. 사망 클립은 **F0–180, 3초**이며 시간은 `프레임 / 60`이다. 제작 중 사용한 1 시작 프레임과 혼용하지 않는다. FBX는 본 동작을 제공하고, Blender 원본의 포즈 마커 및 동봉 클립 JSON/검수 기록이 연결 시점을 제공한다. Unity 이벤트는 별도로 연결한다. Blender 포즈 마커가 FBX 이벤트 채널로 전달되거나 Unity Animation Event로 자동 연결된다고 간주하지 않는다. 실제 소멸 효과는 구현 대기다.

### 시간·동작 계약

| 시점 | 프레임 | 동작 및 Unity VFX 연결 |
| --- | --- | --- |

| 0.35초 | F21 | `RecoilHold`. 몸·의상의 짧은 반동·처짐 동작이 끝나고 그 자세를 유지한다. 소멸은 계속된다. |
| 0.7초 | F42 | `BodyDissolveComplete`. 몸·의상이 완전히 사라진 뒤 해당 그룹 렌더러를 비활성화한다. |
| 1.8167초 | F109 | `StaffImpact`. 지팡이가 바닥에 닿는다. 바닥 충돌 뒤 튀어 오르는 연출을 추가하지 않는다. |
| 2.1333초 | F128 | `StaffSettled`. 지팡이는 바닥에 낮게 누운 자세로 멈춘다. |
| 2.2초 | F132 | `StaffDissolveStart`. 지팡이 3개 렌더러를 한 묶음으로 소멸시키기 시작한다. |
| 2.7초 | F162 | `StaffDissolveComplete`. 지팡이가 완전히 사라진 뒤 해당 그룹 렌더러를 비활성화한다. |
| 3초 | F180 | `DespawnReady`. 남은 효과 정리 및 오브젝트 반환/제거가 가능한 종료 시점이다. |

### 렌더러 그룹

그룹 이름은 구현 시 구분을 위한 명칭이다. 실제 오브젝트 이름은 아래와 같이 정확히 매칭한다.

| 그룹 | 실제 렌더러 이름 |
| --- | --- |
| BodyCloth — 0–0.7초 | `Witch_Head`, `Witch_Neck`, `Witch_Hand_Right`, `Witch_Hand_Left`, `Witch_Eyes`, `Witch_Robe`, `Witch_Sleeve_Right`, `Witch_Sleeve_Left`, `Witch_Pendant` |
| Staff — 2.2–2.7초 | `Witch_Staff_Wood`, `Witch_Staff_Silver`, `Witch_Staff_Crystal_20_Faces` |

### 구현할 항목

- [ ] BodyCloth 전체에 일관된 재·보라색 마력 소멸을 적용한다. 부품별로 따로 꺼져 보이지 않도록 하나의 진행도와 연출 흐름을 사용한다. 눈·손·목걸이도 빠뜨리지 않는다.
- [ ] Staff는 승인된 낙하·접촉·정지 동작을 먼저 재생하고, 2.2–2.7초에 별도의 그룹 진행도로 소멸한다. 몸의 소멸 진행도가 지팡이에 적용되지 않게 한다.
- [ ] 소멸 진행도를 **개체별·그룹별**로 제어한다. 공유 재질의 전역 값을 바꿔 다른 Witch나 다른 클립까지 함께 사라지지 않도록 한다.
- [ ] 기존 UV는 **4×4 팔레트 색상표의 면별 색칸 중심**을 가리키며 연속된 의상 UV가 아니다. 소멸 노이즈는 로컬/월드 위치 또는 별도 UV로 샘플링하고, 기존 색상표 UV만으로 만들지 않는다. BodyCloth 9개 렌더러는 일관된 개체별 진행도를 공유한다. 그림자 패스(ShadowCaster)에도 같은 소멸 기준을 적용하여 사라진 몸의 그림자가 남지 않게 한다.
- [ ] 각 그룹의 소멸이 완료된 뒤 렌더러를 비활성화하고 잔여 효과를 정리한다. **F0에서 몸을 즉시 숨기거나 FBX의 스케일을 0으로 만드는 방식은 사용하지 않는다.**
- [ ] 재사용/풀 반환 후 새로 생성될 때 두 그룹의 진행도, 렌더러 활성 상태, 파티클, 사망 시간·상태를 초기화한다. Idle·Move·Attack·Summon에 소멸 상태가 남지 않게 한다.
- [ ] 게임 연결 담당은 `DeathStart`에서 Witch의 이동·공격·소환을 멈추고 중복 사망 실행을 막는 연결을 확인한다. 이 문서는 게임 코드를 구현하거나 기존 소환체의 생존 규칙을 변경하지 않는다.
- [ ] Unity에서 시간 연결을 구현하고, 동작·셰이더·파티클을 함께 재생하여 아래 기준으로 검수한다.

### 완료 기준

- [ ] 플레이어가 자주 보는 **정면 위 45도**에서 재생·정지·프레임 이동으로 확인한다. F0은 승인된 Idle의 위치·회전·크기와 일치한다.
- [ ] 몸·의상·목걸이가 0–0.7초에 하나의 마법 소멸로 읽히며 빈 로브나 해골 일부가 남지 않는다. 실제 소멸 완료 전에는 동작이 보인다.
- [ ] 지팡이는 손에서 놓여 자연스럽게 쓰러지고, 바닥 접촉 뒤 다시 서거나 크게 튀어 오르지 않는다. 누운 상태에서 2.2–2.7초에 소멸한다.
- [ ] 3초 안에 두 그룹이 모두 사라진다. 파티클 잔상과 그림자도 연출 종료 시점에 맞게 정리된다.
- [ ] Witch 여러 개를 동시에 죽이거나 풀에서 다시 꺼내도 소멸 진행도가 서로 섞이지 않고, 다시 생성된 개체의 다른 클립이 정상 표시된다.

## 공격·소환 VFX와 게임 판정 연결

아래 시점은 승인된 1배속 클립의 로컬 프레임이다. 게임에서 클립을 변속하면 이벤트도 같은 클립 상대 시점을 따른다. 피해·생성은 이벤트당 한 번만 처리하며, 애니메이션 시작과 타격 시점에서 중복 실행하지 않는다.

| 적·클립 | 클립 길이 | 연결 시점 | 개발할 연결 |
| --- | --- | --- | --- |
| Skeleton Attack | 0.5초 / F0–30 | F12 / 0.2초 | 근접 타격 판정·피해를 한 번 실행한다. 칼을 휘두르는 동작 자체는 승인된 본 애니메이션이다. |
| Witch Attack | 1초 / F0–60 | F33 / 0.55초 | 지팡이 끝에서 투사체를 한 번 발사하고 발사 VFX를 연결한다. 피해는 이 프레임에 직접 적용하지 않고 투사체의 명중·도착 처리에서 적용한다. |
| Witch Summon | 1.5초 / F0–90 | F21 / 0.35초 | 해골 2체 생성 및 각 Skeleton Spawn 동작 시작과 소환 VFX를 연결한다. 소환 클립 길이는 반복 주기가 아니다. |

Witch 공격 투사체의 기획 색은 **하늘색과 회빛이 섞인 구체**다. 사망의 **재·보라색 마력**과 구분한다. 공격 발사·투사체·명중 효과, 소환 파티클/셰이더는 각각 개발 대기이며 FBX에 구워 넣은 효과가 아니다. 기획상의 명목 공격 빈도는 Witch 초당 1회, Skeleton 초당 2회다. Witch는 등장 이후 **10초마다 해골 2체**를 소환하도록 별도 반복 제어가 필요하다. 이미 생성된 해골은 Witch와 별개이므로 Witch 사망에 함께 제거하지 않는다. 자세한 최종 계약은 [Witch_Clips.json](../../Art/Enemy_Models/05_Witch/Witch_Clips.json)과 [Skeleton_Clips.json](../../Art/Enemy_Models/06_Skeleton/Skeleton_Clips.json)을 따른다.

## 현재 게임 코드와 후속 연결 작업

2026-11-02 KST 소스 확인 기준이며, 아래 코드는 이번 문서 작업에서 수정하지 않았다.

- [AttackState](../Assets/_Project/_Scripts/Enemy/FSM/AttackState.cs)는 `Attack()`을 즉시 호출한 뒤 `1 / AttackSpeed`만큼 기다린다(72–85행). [EnemyBase](../Assets/_Project/_Scripts/Enemy/EnemyBase.cs)의 기본 `Attack()`은 즉시 `TakeDamage()`를 호출하며(111–125행), [MeleeEnemy](../Assets/_Project/_Scripts/Enemy/Inherit/MeleeEnemy.cs)는 이를 그대로 사용한다. Skeleton은 애니메이션 시작과 실제 타격을 분리하여 F12의 한 번짜리 판정 창에 연결해야 한다.
- [RangedEnemy](../Assets/_Project/_Scripts/Enemy/Inherit/RangedEnemy.cs)는 `Attack()` 호출 시 즉시 투사체를 생성·발사한다(22–71행). Witch는 실제 생성·발사와 발사 VFX를 F33에 연결해야 한다. 현재 `_projectileSpeed`는 별도 고정 설정값이므로 기획의 공격속도에 따른 투사체 속도 비례도 게임 담당이 연결해야 한다(20, 71행). [Projectile](../Assets/_Project/_Scripts/Enemy/Projecile/Projectile.cs)은 이동 완료 후 피해를 적용하며(37–40, 55–57행), 발사자 사망 또는 대상 소멸 시 피해를 취소하는 가드가 있다(46–53행). 현재 도착 기반 판정의 변경이나 추가 충돌 판정은 게임 담당의 별도 범위다.
- [DeadState](../Assets/_Project/_Scripts/Enemy/FSM/DeadState.cs)는 `Dead()`를 호출한다(19–21행). [EnemyBase](../Assets/_Project/_Scripts/Enemy/EnemyBase.cs)의 `Dead()`는 이동·공격/코루틴 중단, 충돌체 비활성화, 보상 및 웨이브 사망 통지를 수행한 뒤 `DeadAnim()`을 시작한다(129–156행). 현재 기본 `DeadAnim()`은 루트를 1.5m 아래로 0.5초간 이동시킨 뒤 파괴한다(163–177행). 승인된 **Witch 3초 / Skeleton 0.6초**의 표시와 충돌하므로 적별 사망 표시·제거 시점으로 교체해야 한다. 게임 판정상 사망과 화면에서 오브젝트를 제거하는 시점을 구분한다.
- Witch 소환 10초 반복, 생성된 Skeleton의 1.5초 Spawn 완료 전 행동 제한, 공격 시점 및 사망 VFX를 연결하는 게임 로직은 후속 통합 항목이다. FBX를 가져오는 것만으로 연결이 완료되지는 않는다.

## Skeleton VFX·후처리 범위

Skeleton의 승인된 사망은 **본 관절이 분리되어 무너지는 0.6초 동작(F0–36)**이다. Witch의 몸·의상 디졸브를 Skeleton에 자동 적용하지 않는다. Skeleton 전용 디졸브·재 파티클은 이번 승인에 포함하지 않으며 별도의 신규 VFX 요구로 추가하지 않는다. 사망 표시를 끝까지 재생한 뒤 제거하도록 현재 공통 0.5초 하강/제거 처리를 적별로 맞추는 통합 검수가 남아 있다. [Skeleton 인계](../../Art/Enemy_Models/06_Skeleton/Handoff.md)를 함께 확인한다.

프로젝트에는 URP용 PC/Mobile 렌더 파이프라인과 Volume 설정이 존재한다. 최종 팔레트·뼈·금속·수정의 색과 광택은 실제 게임 조명 및 URP 재질에서 확인해야 한다. 팔레트의 밝은 색이나 콘셉트의 빛 표현을 **발광 셰이더·Bloom이 FBX에 구워졌다는 의미로 해석하지 않는다.** 이번 승인으로 새 Bloom·윤곽선·전역 후처리를 필수 요구사항에 추가하지 않는다. 기존 후처리 설정의 존재와 이번 모델에 대한 실제 Unity 검수 완료 여부는 별개다.

현재 기록 범위는 개발 항목과 애니메이션/VFX·게임 판정의 연결 계약이다. **실제 셰이더, 파티클, 게임 코드 연결 및 Unity 실행 검수는 아직 수행하지 않았다.** 최종 파일과 상태는 [Witch 인계](../../Art/Enemy_Models/05_Witch/Handoff.md), [Witch_Clips.json](../../Art/Enemy_Models/05_Witch/Witch_Clips.json), [Skeleton 인계](../../Art/Enemy_Models/06_Skeleton/Handoff.md), [Skeleton_Clips.json](../../Art/Enemy_Models/06_Skeleton/Skeleton_Clips.json)을 따른다.
